## 2. Background and purpose

The purpose of this internship is to apply knowledge and skills acquired during university studies to ICT work assignments in software development and research software engineering. The main project is **The Simulation of Collective Intelligence in Agile Teams: a Transparent Testbed**, an academic prototype that models collective intelligence (CI), agile team effectiveness, and human–AI teaming across software development sprints.

The internship connects directly to my degree studies and thesis work. It provides practical experience in Python development, simulation design, technical documentation, literature-based modelling, and academic dissemination.

## 3. Learning objectives

The internship is planned to fulfil the following learning objectives for practical training:

## 4. Planned duties and assignments

### 4.1 Software development

- Design and implement **The Simulation of Collective Intelligence in Agile Teams: a Transparent Testbed** in Python with a Streamlit user interface.
- Build core modules: simulation engine, team/backlog generation, AI support, metrics, and experiments.
- Add advanced features: externalized weights, preset scenarios, mixed backlogs, task dependencies, defect rework, Scrum roles, and export functions.
- Implement automated tests and run validation experiments (Monte Carlo, sensitivity analysis).

### 4.2 Research modelling and documentation

- Review collective intelligence and agile effectiveness literature.
- Map research constructs to testbed variables and document assumptions transparently.
- Produce UML/conceptual diagrams and performance analysis documents.
- Integrate supervisor feedback aligning the model with Riedl (2021), Kommol et al. (2025), Hackman/Wageman, and agile/Scrum literature.

### 4.3 Academic dissemination support

- Prepare demo/poster submission materials for a collective intelligence conference context.
- Create parameter dictionaries, architecture descriptions, and presentation-ready summaries.
